# C4 → Video Walkthroughs

Turning a project's C4 diagrams into narrated code-walkthrough videos.

- **Watch the demos:** https://nickstrad.github.io/c4-video-walkthroughs/ (phone-friendly)
- **The plan, the four toolchain options, and POC results:** [overview.md](overview.md)

The site is `site/index.html`; `.github/workflows/pages.yml` copies it, the
four POC demo videos, and one poster frame each into the Pages artifact.
